# Details spot-check index

The stories and similar names for the name sheet were written in 20 batches (PRD name-detail §6.5, most given in 2024 first). Each batch has a spot-check file with 10 random entries, seeded by the batch number so the same 10 come up every time (`node scripts/names-content/spot-check-details.mjs <batch>`).

**Please read at least 3 of them.** A good spread: batch 1 (the most common names, seen most often), one middle batch with Arabic and Yiddish names (batch 11 or 19), and batch 20 (the rarest names, where a wrong fact is least likely to be noticed). Mark each row OK or write what to change; the overall picture (coverage, null stories, symmetry fills, drops) is in [DETAILS-REPORT.md](DETAILS-REPORT.md).
